\# OpenCV Assignments



This repository contains solutions for various OpenCV assignments, including image processing, feature matching, geometric transformations, filtering, contour detection, thresholding, face detection, video processing, and camera calibration.



\## Topics Covered



\- Color Space Conversion

\- Image Blending using ORB Feature Matching

\- Geometric Transformations

\- Noise Addition and Filtering

\- Edge and Contour Detection

\- Thresholding and Morphological Operations

\- ORB Feature Matching

\- Haar Cascade Face Detection

\- Real-Time Video Processing

\- Camera Calibration and Lens Undistortion
